# Changelog

## 0.1.2 - 2026-08-13

- Preserve DocFerry's validated source thumbnail when saving or sharing a generated
  Media-to-Note note.

## 0.1.1 - 2026-08-13

- Prevent Obsidian's inline file title from duplicating a matching leading note title.
- Clarify payment, account, network, Vault, clipboard, telemetry, and source disclosures.
- Minify production bundles and run the complete repository through the release lint gate.
- Use Obsidian Vault APIs for imported assets and reject non-HTTPS account avatars.
- Keep the mobile completion prompt visible before opening a long note, with direct
  Open note, Share, and Keep private choices.
- Remove unreliable generated remote source-preview hotlinks from saved notes.

## 0.1.0 - 2026-08-12

- Add one mobile-first link entry for public Share import and Media-to-Note.
- Save completed generated notes privately and open them before optional sharing.
- Add durable processing recovery, cancellation, retry, and deletion controls.
- Add paginated owner Shares with detail, access, stop, and history deletion actions.
- Show display-only account identity, shared DocFerry Pro state, and owner-safe usage.
- Add hosted login with internal one-time exchange and Obsidian return handling.
- Store the product session with Obsidian SecretStorage and keep profile data ephemeral.
