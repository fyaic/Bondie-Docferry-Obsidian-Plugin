# Bondie-Docferry 0.1.0

This is the first GitHub release candidate for Obsidian Community review.

It includes the mobile-first single-link workflow, native private Vault save, explicit
DocFerry sharing, paginated Share management, processing recovery, display-only
account identity, and shared DocFerry Pro usage. Public catalog submission is not part
of this release and will be completed separately by the product team.

Install assets: `main.js`, `manifest.json`, and `styles.css`.
