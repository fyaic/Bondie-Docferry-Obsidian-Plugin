# Support

## Plugin Help

Use this repository's GitHub issues for reproducible plugin bugs and feature requests.
Include the plugin version, Obsidian version, platform, and steps to reproduce. Do not
include private links, note content, Vault paths, account details, or session values.

Security concerns belong in GitHub private vulnerability reporting as described in
[SECURITY.md](SECURITY.md).

## Account And Entitlement Recovery

Use `Account & membership` in the plugin to open Bondie Account Center. It owns profile,
session, device, membership, and account recovery. Signing out and back in refreshes a
stale product session; it does not create or purchase a second membership.

## Subscription Management

DocFerry is the only checkout and subscription owner. Use the DocFerry/Bondie account
surfaces linked from Account Center to view current pricing and terms, manage or cancel
the subscription, and use the support path shown there for billing or refund requests.
The Obsidian plugin does not collect card data or issue refunds.
